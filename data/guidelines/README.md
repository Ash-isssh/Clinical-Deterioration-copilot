# Guideline corpus

The demo uses a small local corpus so it can run without a hosted vector database or an external API.

Bundled PDFs:

- `documents/NICE_CG50.pdf`
- `documents/NICE_CG187.pdf`

The prebuilt retrieval index is `index.json`.

`NG253` is listed in `sources.json` as source metadata only; its PDF is not bundled in this repository.
